# Portfolio — Abhishek Patro Balivada

Single-file static site (index.html, no build step). Deploy as-is to
GitHub Pages, Netlify, or Vercel.

## Deploy to GitHub Pages
1. Push this repo to GitHub (see root-level SETUP.md for commands).
2. In the repo: Settings → Pages → Source → deploy from `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/portfolio-site/`.
